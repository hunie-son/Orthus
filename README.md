# PoC

This directory contains the proof-of-concept artifacts used in our evaluation.

## Layout

- `BM1/`  
  Plaintext TDX baseline benchmark.

- `BM2/`  
  Software-only FHE baseline with native CKKS bootstrapping.

- `BM3/`  
  TDX-assisted FHE benchmark with ciphertext refresh inside a trusted domain.

- `TDX-Flush-Flush-PoC/`  
  Flush+Flush side-channel proof-of-concept suite, including native and TDX-based experiments.

## Note

Each subdirectory has its own README with detailed build, run, and result information.
